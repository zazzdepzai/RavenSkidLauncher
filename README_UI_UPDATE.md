# RavenXD UI update

This build adds:

- Fixed vector sidebar icons matching the Home / Mods / Accounts / Settings layout, plus Logs.
- Hover and selected states for sidebar navigation.
- Redesigned glass/blue buttons with hover, press, border and glow states.
- Logs page with live in-launcher activity output.
- Persistent launcher log at `%APPDATA%\\RavenXD\\launcher.log`.
- Clear Log and Open Folder actions.
- Five theme presets: Raven Blue, Midnight, Purple, White Glass and Custom.
- Custom theme color controls for accent, background and glass/card surface.
- Theme settings persisted in `%APPDATA%\\RavenXD\\ui.cfg`.
- Existing 39-effect D3D11 shader pack settings retained.
- Existing Discord RPC integration retained.
