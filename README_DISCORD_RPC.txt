RavenXD Discord RPC

The launcher can rotate between multiple Discord Application IDs.

1. Put your registered Discord Application IDs in discord_client_ids.txt, one per line.
2. Restart the launcher.
3. Every 6 seconds the RPC presence changes and a random configured Application ID may be selected.

Important: random/nonexistent Discord IDs will not work. Every ID must be a real Discord application ID that you control.
