# RavenXD Minecraft Launcher

The authenticated flow now opens the RavenXD Minecraft launcher directly.

Features:
- Minecraft 1.8.9 Forge + RavenXD v2
- Minecraft 1.8.9 Vanilla mode
- RavenXD v2 installer
- Modrinth Forge 1.8.9 mod search/install
- Account Manager
- Discord RPC
- Ice effect assets
- RavenXD Windows icon

Requirements:
- Windows x64
- Java 8 for Minecraft 1.8.9
- A compatible local Minecraft/Forge installation

Note: this project uses the local/offline username flow; it does not implement Microsoft account authentication.
