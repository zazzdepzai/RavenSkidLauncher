# RavenXD Custom Shader Pack integration

RavenXD now includes a native Direct3D 11 UI shader layer with the 39 live looks from the `ff0l/Custom-Shader-Pack` catalog as selectable launcher effects.

Catalog: Color Bends, Galaxy, Lightning, Light Rays, Line Waves, Liquid Chrome, Liquid Ether, Silk, Particles, Pixel Snow, Rain, Plasma, Prismatic Burst, Aurora, Caustics, Ember, Fog, Iridescence, Smoke, Marble, Ripple, Magnet, Tunnel, Warp, Flame, Kaleido, Cells, Water, Matrix, Lava, Horror Spiral, Creation, Star Nest, Julia, Electric, Hexagons, Grain, Scanlines, Flaring.

The integration is a RavenXD-native D3D11 implementation inspired by the source pack's visual catalog and interaction model rather than a verbatim copy of its shader source. It is rendered behind Dear ImGui, so it does not modify the Minecraft renderer.

Reference: https://github.com/ff0l/Custom-Shader-Pack
