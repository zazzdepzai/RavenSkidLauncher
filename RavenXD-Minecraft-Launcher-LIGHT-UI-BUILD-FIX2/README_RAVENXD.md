# RavenXD Minecraft Launcher

RavenXD Minecraft launcher source.

Features:
- Minecraft 1.8.9 launcher UI
- Home / Misc / Settings navigation
- Light / Dark theme
- Modrinth integration
- RavenXD v2 configurable download
- Discord RPC
- Java / RAM / game-directory settings

Build:
`msbuild .\imgui-menu.sln /m /p:Configuration=Release /p:Platform=x64 /p:PlatformToolset=v143`
