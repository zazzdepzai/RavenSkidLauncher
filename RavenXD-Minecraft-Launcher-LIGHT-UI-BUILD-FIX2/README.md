# RavenXD Minecraft Launcher

Clean Minecraft-only launcher build.

Features:
- Login/Register
- Minecraft 1.8.9 installation download from Mojang version metadata
- Forge 1.8.9 + RavenXD v2 path
- Vanilla 1.8.9 installation
- Modrinth mod search/install
- Account Manager
- Discord RPC
- Java and game-directory settings
- RavenXD icon
- Minimal ICE/particle-ready ImGui UI
- GitHub Actions MSBuild x64 artifact

This project does not include the unrelated cheat/menu assets from the previous build.
